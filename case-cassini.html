Case study

Making Cassini's Legacy Accessible

Usability Testing and Web Redesign for the Cassini Mission Archive and Cassini Event Calendar

  • Usability Testing
  • Web Design & UX
  • Software Design
  • Technical Documentation

Challenge

Thirteen years of Cassini data were hard for researchers and scientists to navigate, from the archive pages to the event calendar dataset.

My Solution

I took part in usability testing of the Cassini Mission Archive web pages and helped redesign them based on what we learned. I supported the restructuring and redesign of the Event Calendar data repository, and wrote the technical documentation and user manuals that future users and maintainers rely on.

View the archive ↗See the event calendar ↗

Impact

Working with fellow interns, Cassini mission web developers, and mission scientists, I helped produce an organized data repository that sorts Cassini’s datasets by the spacecraft’s significant events and flybys. Researchers and scientists can now go straight to the moments that matter for their work.
